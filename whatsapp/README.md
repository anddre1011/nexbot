# whatsapp/

Flujos de WhatsApp y webhooks de Meta — punto de entrada de todos los mensajes entrantes y salientes.

**Stack:** WhatsApp Cloud API (Meta), n8n (flujos), Typebot (chatbots estructurados).

**Contenido futuro:**
- `webhooks/` — handlers para mensajes, estados de entrega, errores
- `flows/` — definiciones de flujos n8n exportados (JSON)
- `templates/` — plantillas HSM aprobadas por Meta
- `utils/` — helpers para formatear payloads de WhatsApp
