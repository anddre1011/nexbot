# NexBot

SaaS de automatización de WhatsApp con inteligencia artificial — multi-tenant.

## Módulos

| Carpeta | Descripción |
|---------|-------------|
| `frontend/` | Dashboard web (Next.js) |
| `backend/` | API y lógica de negocio (Node.js) |
| `whatsapp/` | Webhooks y flujos Meta + n8n |
| `ai-agent/` | Agente conversacional OpenAI |
| `database/` | Esquemas y migraciones Supabase |
| `docs/` | Arquitectura y documentación |

## Stack
Next.js · Supabase · n8n · Typebot · OpenAI · WhatsApp Cloud API
